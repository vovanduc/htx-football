# Sa bàn v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Trang tĩnh mobile-first hiển thị sa bàn 8 người của HTX4.0 FC với 6 chiến thuật (tấn công/phòng thủ), tình huống, nhiệm vụ từng vị trí, quiz đứng đúng chỗ, thay người, bài học.

**Architecture:** Data (`js/data/*.js`) mô tả người + frame chiến thuật bằng tọa độ chuẩn hóa 0–100; `js/engine.js` thuần (test bằng node); `js/app.js` render DOM + sự kiện; CSS transition lo animation.

**Tech Stack:** HTML/CSS/JS ES modules, không dependency; `node --test` (Node 22).

**Spec:** docs/specs/2026-10-26-sa-ban-chien-thuat-design.md

## Global Constraints
- 8 slot trên sân: `GK, LB, CB, RB, LM, CM, RM, ST`; tọa độ `[x,y]`, `x` 0–100 trái→phải, `y` 0–100 (0 = goal đối phương).
- Không build step; mọi đường dẫn tương đối (GitHub Pages subpath `/htx-football/`).
- Text giao diện tiếng Việt có dấu; đùa vào chiến thuật, không vào con người.
- Avatar: `assets/avatars/<id>.jpg`.

## Review Focus
- localStorage lineup cũ trỏ tới id không còn tồn tại → bỏ qua, về lineup mặc định (test `sanitizeLineup`).
- Thay người khi chọn chính người đó / hai người cùng trên sân → hoán đổi slot hợp lệ, không mất ai (test `swapPlayers`).
- Kéo thả quiz ra ngoài sân → kẹp tọa độ 0–100 (test `clampPoint`).
- Màn hình 360px: sân + tên không tràn ngang (kiểm tra trình duyệt).
- Mất localStorage (private mode) → app vẫn chạy (try/catch quanh mọi truy cập).

### Task 1: Scaffold + roster + engine

**Files:** Create `package.json` (scripts.test=`node --test tests/`), `js/data/roster.js`, `js/engine.js`, `tests/engine.test.js`; modify `init.sh` (chạy `node --test tests/`).

**Interfaces — Produces:**
- `roster.js`: `export const TEAM = {name, captainId}`; `export const PLAYERS = [{id, name, number|null, avatar, role}]`; `export const SLOTS = ['GK','LB','CB','RB','LM','CM','RM','ST']`; `export const SLOT_LABELS = {GK:'Thủ môn', ...}`; `export const DEFAULT_LINEUP = {GK:'diep', LB:'linh', CB:'vulinh', RB:'thien', LM:'son', CM:'duc', RM:'quan', ST:'cuong'}`.
- `engine.js`: `sanitizeLineup(saved, players, fallback) -> lineup`; `swapPlayers(lineup, aId, bId) -> lineup` (b có thể là dự bị); `benchOf(lineup, players) -> Player[]`; `distance(a,b) -> number`; `scoreDrop(dist) -> {points, verdict}` (≤6 → 100 "Chuẩn như Pep", ≤12 → 70 "Tạm được, lệch xíu", ≤20 → 40 "Hơi lạc trôi", else 0 "Đi lạc sang sân bên cạnh"); `clampPoint([x,y]) -> [x,y]`.

- [ ] Viết test cho từng hàm (giá trị như trên; swap sân↔dự bị, sân↔sân, id lạ → không đổi).
- [ ] `npm test` → FAIL; implement; `npm test` → PASS; commit.

### Task 2: Data chiến thuật + test toàn vẹn

**Files:** Create `js/data/tactics.js`, `js/data/lessons.js`, `tests/data.test.js`.

**Interfaces — Produces:** `export const TACTICS = [{id, name, nickname, tiredness:1..5, when, summary, phases:{attack:Frame, defend:Frame}}]`; `export const SCENARIOS = [{id, name, phase:'attack'|'defend', frame:Frame}]`; `Frame = {ball:[x,y], us:{[slot]:[x,y]}, them:[[x,y]]×8, arrows:[{from:slot, to:[x,y], kind:'run'|'pass'}], duties:{[slot]:string}, joke:string}`; `export const LESSONS = [{date, opponent, result, notes:[string]}]`.
- 6 tactics: `can-bang` (3-3-1 nền), `pressing-cao`, `khoi-thap-phan-cong`, `kiem-soat-tam-giac`, `danh-bien-chong-bien`, `kem-nguoi`.
- Scenarios: bóng cánh trái (atk), bóng cánh phải (atk), bóng trung lộ (atk), thủ môn phát bóng (atk), phạt góc tấn công (atk), đối thủ bóng ở cánh (def), đối thủ bóng trung lộ (def), mất bóng 5 giây (def).

- [ ] Test: mọi frame có đủ 8 slot, 8 đối thủ, tọa độ trong [0,100]; duties đủ 8 slot; id duy nhất; phòng thủ: GK y ≥ 88; số áo không trùng; mọi avatar file tồn tại.
- [ ] FAIL → viết data → PASS; commit.
